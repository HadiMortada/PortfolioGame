Scientific controls
• Ground truth is computed in your browser before the request.
• The correct candidate ID is never included in the API payload.
• Exactly one Jev decision is allowed per measured round.
• No retry or second chance is counted as the same round.
• Every round exposes its random seed for reproducibility.
• Random-choice baseline is shown implicitly as 1/N.
What Jev must do
Read a natural-language priority policy, compare all candidate incidents, apply the ordered tie-break rules, and select one candidate using a single structured Choice response.
Why this fits Jev
It is a one-shot, high-cardinality decision problem rather than a long sequential search.
